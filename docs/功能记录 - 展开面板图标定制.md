## 三、实现要点

- 图标渲染优先级：**图片（.png）→ Icons.xaml 矢量键 → 文字/emoji**，向后兼容旧配置。
- 面板仍为「纯图标 / 无汉字」，文字仅作按钮 `ToolTip` 悬停提示。
- 图片用 `pack://` URI + `BitmapCacheOption.OnLoad` 加载后 `Freeze()`，避免文件锁与线程问题。
- 用户上传原图不改动；切分产物写入项目 `Assets`，可在 Windows 编译时自动作为资源打包。

## 四、校验

- C# 花括号配平：`FloatingBallWindow.xaml.cs` / `BallSettings.cs` / `BallConfigService.cs` 均 `balance=0, min=0`。
- `csproj` 已含 4 条 `panel_*.png` 的 `Resource Include`。
- 切分产物均有非空 alpha 边界（四图独立干净）。
- 预览图：`/mnt/cos/artifacts/panel-icons-preview.png`（依次 剪切板/便签/待办/文件备注，深色底便于查看透明边缘）。

## 五、后续建议

- 在 Windows 上执行 `dotnet build FileMemo.sln -c Debug` 编译，运行后右键悬浮球展开面板查看效果。
- 如需更大图标：调整 `MakeActionIcon` 中 `Image.Width/Height`（当前 24）与按钮尺寸（当前 34×34）。
