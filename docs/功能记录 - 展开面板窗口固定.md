# 功能记录 —— 展开面板窗口固定

> 需求：为展开面板四个入口打开的窗口（打开便签 / 打开剪切板 / 打开待办 / 打开文件文件夹备注）
> 增加「窗口固定」功能：固定后窗口**置顶显示**，且**不随批量收纳 / 最小化**；状态跨会话保留。

## 一、涉及文件

| 文件 | 改动 |
| --- | --- |
| `Services/WindowRegistry.cs` | 新增固定集合与 API：`IsPinned` / `SetPinned` / `PinnedCount`；`CollapseAll` / `ReleaseAll` / `MinimizeAll` 跳过已固定窗口 |
| `Services/WindowPin.cs` | **新增**：`PinKind` 枚举 + `WindowPin` 辅助类（`ApplyOnLoad` / `Toggle` / `Apply` / `IsPinned`），负责置顶、持久化 |
| `Services/SettingsService.cs` | 新增 4 个开关：`PinQuickNote` / `PinQuickTask` / `PinClipboard` / `PinFileNote` |
| `Views/QuickNoteWindow.xaml(.cs)` | 标题栏右侧新增图钉按钮 |
| `Views/QuickTaskWindow.xaml(.cs)` | 标题栏右侧新增图钉按钮 |
| `Views/ClipboardPanelWindow.xaml(.cs)` | 搜索框右侧新增图钉按钮（区分于列表项固定 `Pin_Click`） |
| `Views/FloatingNoteWindow.xaml(.cs)` | 标题栏在关闭按钮左侧新增图钉按钮 |

## 二、固定语义

- **置顶**：固定后 `Window.Topmost = true`，始终浮于最上层。
- **免疫批量操作**：`CollapseAll`（一键收纳）、`MinimizeAll`（最小化全部）、`ReleaseAll`（释放）均跳过已固定窗口。
- **状态持久化**：写入 `settings.json`，下次打开该窗口自动恢复固定态并置顶。
- **视觉反馈**：图钉描边在固定时用主题色（`PrimaryBrush`），未固定时为次要色（`TextSecondaryBrush`）；提示文字在「固定窗口…」与「已固定（点击取消）」间切换。

## 三、按键分布

| 窗口 | 触发入口 | 图钉位置 | 事件 |
| --- | --- | --- | --- |
| 快速便签 | 面板「打开便签」 | 标题右侧 | `Pin_Click` |
| 快速待办 | 面板「打开待办」 | 标题右侧 | `Pin_Click` |
| 剪贴板面板 | 面板「打开剪切板」 | 搜索框右侧 | `WindowPin_Click` |
| 文件文件夹备注 | 面板「打开文件文件夹备注」 | 关闭按钮左侧 | `Pin_Click` |

## 四、实现要点

- 复用主球的 `WindowRegistry`（`BallWindows`），将「固定集合」与「登记集合」分离，固定只影响批量操作与置顶，不改变登记关系。
- 窗口关闭时自动从固定集合移除，避免悬挂引用。
- 所有写操作（置顶、持久化）均 `try/catch`，单个窗口固定失败不影响主程序。

## 五、校验

- C# 花括号配平：`WindowRegistry.cs`、`WindowPin.cs`、`SettingsService.cs` 及四个窗口代码后置均
  `balance=0, min=0`。
- XAML 标签闭合：四个窗口 `Grid` / `StackPanel` / `DockPanel` / `Border` / `Button` / `Path` 配平一致。
- 事件处理器与命名空间均在位（`Pin_Click` / `WindowPin_Click` / `RefreshPinVisual` / `using FileMemo.App.Services`）。
- 资源键核对：`IconPin` / `IconBase` / `IconSmall` / `CaptionButton` / `PrimaryBrush` / `TextSecondaryBrush` 均存在。
- 接线核对：`App.BallWindows`（`WindowRegistry`）、`Settings.Save()` 均存在。

## 六、后续建议

- 在 Windows 上执行 `dotnet build FileMemo.sln -c Debug` 做最终编译确认，运行后点面板图标打开窗口、点图钉验证置顶与「一键收纳」豁免。
- 可扩展：记住固定窗口的位置；固定数量上限提示；固定状态在「设置」中集中管理。
