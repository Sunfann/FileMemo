## 三、悬浮图标样式：吸附近乎透明 / 呼出半透明

新增两档不透明度常量与统一的目标值计算：

```csharp
private const double DockedOpacity   = 0.10;   // 贴边收拢：近乎透明，仅留一道淡影
private const double RevealedOpacity = 0.72;   // 呼出（滑出/悬停/自由漂浮）：半透明

private double TargetOpacity()
{
    if (_state is OrbState.LongPress1 or OrbState.LongPress2
        or OrbState.ExitAnimation or OrbState.Destroy)
        return 1;                       // 长按/退出动画期间保持全亮，保证可读性
    return (_snapped && !_revealed) ? DockedOpacity : RevealedOpacity;
}

private void FadeToTargetOpacity(int ms = 200) { /* BeginAnimation(OpacityProperty, ...) */ }
```

接入点：

- `BuildVisual()` 末尾：`Opacity = TargetOpacity();`（启动落位）；
- `Reveal()`（呼出）：面板滑出 + `FadeToTargetOpacity(220)` → 半透明；
- `Retract()`（收回）：面板收起 + `FadeToTargetOpacity(300)` → 近乎透明；
- `FinishDrag()`：拖拽结束后按当前形态淡入对应档位；
- `RestorePosition()`：启动时吸附态直接以 `DockedOpacity` 呈现；
- `PlayIntroAnimation()`：首次出现淡入目标改为 `TargetOpacity()` 而非固定 1。

同时保留原有「贴边小凸起 ↔ 滑出」位移动画（`CollapsedShift` / `RevealedShift` / `_sceneShift`），
即吸附时主球只在屏幕边缘露出 14px 的小凸起，且整窗近乎透明。

## 四、展开面板：纯图标、一行从右到左

`BuildActionPanel()` 重写为**水平面板**：

- 动作项容器改为 `StackPanel { Orientation = Horizontal }`，一行排列；
- 停靠右边缘时 `FlowDirection = RightToLeft` → 第一个动作（便签）在最右侧贴着悬浮图标，
  其余（剪切板 → 待办 → 文件文件夹备注）依次向左排，即「从右到左」；停靠左边缘时镜像为从左到右；
- 每个动作项由 `MakeActionIcon()` 生成：**36×34 圆角磁贴，仅图标，无任何汉字**；
  图标优先按 `Icons.xaml` 矢量资源键（IconNote / IconClipboard / IconCheckSquare / IconFolder）渲染，
  失败时回退为单个符号字符；悬停仅做高亮 + 微放大反馈，文字说明只出现在 ToolTip；
- 面板坐标按「滑出后」的屏幕布局反推画布坐标（`screenLeft - shift`），
  保证 4 个图标（约 170px 宽）在滑出态完整可见、不会压到悬浮图标；
  收拢时面板随场景位移退到画布外（不可见、不响应命中）；
- 自由漂浮（未吸附）时面板改为悬浮图标**下方横排**，仍为一行从右到左；
- 新增 `_bandX0/_bandX1/_bandCy/_bandHalfH` 面板矩形热区，光标从球移向面板图标时不再误触发收回；
- 右键悬浮图标（`ToggleRing`）现在统一控制整个动作面板的开关（`RingEnabled`）。

## 八、第二轮修复：展开面板不显示 + 设置页内容更新

### 问题现象

升级后悬停悬浮图标，只有本体滑出，**展开面板不出现**。

### 根因

第一轮实现把面板构建同时挂在两个开关上：

```csharp
if (!S.MainBall.ShowSatellite || !S.MainBall.RingEnabled) return;
```

其中 `RingEnabled` 是旧版「右键切换光环」用的开关。旧版中只要右键点过悬浮球，
`RingEnabled=false` 就被持久化到 `ball.json`；升级后这个残留状态把新面板永久挡在构建之外。
此外老配置的迁移（v3）只在「缺少 OpenFileNotes 动作」时追加一颗卫星，若卫星列表被用户改空 /
禁用，或 `ShowSatellite` 被关掉，同样不会出现面板。

### 修复内容（4 个文件）

1. **`FloatingBallWindow.xaml.cs`**
   - 面板构建只由「显示展开面板」开关（`ShowSatellite`）控制，移除 `RingEnabled` 拦截；
   - 右键悬浮图标改为「展开 / 收起面板」（切换 `ShowSatellite` 并即时重建），主球提示同步更新；
   - 吸附 / 呼出两档不透明度改为配置驱动：`MainBall.DockedOpacity`（默认 0.10）、
     `MainBall.RevealedOpacity`（默认 0.72），替代原硬编码常量。
2. **`BallSettings.cs`**：`MainBallConfig` 新增 `DockedOpacity` / `RevealedOpacity` 字段；
   同步更新 `Satellites` / `ShowSatellite` / `BallDefaultsVersion` 注释。
3. **`BallConfigService.cs`**：配置版本号 v3 → **v4**。迁移逻辑改为——对出厂默认的 4 个面板动作
   「缺哪个补哪个、存在则确保 `Enabled=true`、图标 / 文案为空则回填默认」，并统一把
   `ShowSatellite` 重置为 `true`，一次性消除历史配置导致的「面板不出现」。
4. **`MainWindow.xaml.cs`**：设置页「桌面悬浮球」分组更新为「**桌面悬浮图标**」，内容调整为：
   - 启用悬浮图标（吸附时近乎透明 / 悬停呼出半透明并展开面板的说明）；
   - 图标直径（38 ~ 56）；
   - 吸附屏幕边缘（开关）；
   - 吸附时透明度（0.02 ~ 1.0，近乎透明推荐 0.10）；
   - 呼出时透明度（0.05 ~ 1.0，半透明推荐 0.72）；
   - 显示展开面板（便签 / 剪切板 / 待办 / 文件文件夹备注，纯图标一行从右到左）；
   - 呼吸动画（开关）；
   - 悬浮图标位置复位、配置文件入口。

所有改动立即生效：设置项变更走 `App.RebuildFloatingBall()`（保存 → 关闭 → 重建悬浮图标）。

## 九、第三轮修复：展开面板与悬浮图标同一行

### 现象

贴边悬停呼出时，展开面板出现在悬浮图标**下方一行**，而非同一行（见 PixPin_2026-09-30_23-33-18.png）。

### 根因

启动时序问题：`Loaded` 里先 `BuildVisual()`（构建面板时 `_snapped` 仍是字段默认值 `false`），
面板走了「自由漂浮 → 球下方横排」分支；随后 `RestorePosition()` 才把 `_snapped` 置为 true
并整体位移到屏幕边缘——面板被定格在球下方。控制点方位依赖的 `_side` 存在同样的时序问题。

### 修复（`FloatingBallWindow.xaml.cs`）

- `Loaded` 中在 `BuildVisual()` 之前先赋值 `_snapped = S.MainBall.SnapToEdge` 与 `_side = DetermineSide()`；
- 新增 `DetermineSide()`：按记忆位置相对屏幕中线推断贴边方向（默认右侧），`RestorePosition()` 复用同一推断；
- 吸附态面板坐标本就以球心水平线为基准（`top = Center - sz.Height / 2`），修复后面板与悬浮图标严格同一行；
- 自由漂浮（关闭「吸附屏幕边缘」）时面板仍为球下方横排——240×240 画布宽度容纳不下同行横排，属预期行为。
