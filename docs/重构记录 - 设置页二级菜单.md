# 设置页重构记录 —— 二级菜单（分类导航）

> 背景：设置项已经非常多（20 个分组、60+ 设置行），单页纵向堆叠导致滚动冗长、找不到项。
> 目标：新增**二级菜单**，左侧分类导航 + 右侧内容，一次只看一类，减少滚动与认知负担。

## 一、改动概览

| 文件 | 改动 |
| --- | --- |
| `Views/MainWindow.xaml` | 设置分区（`MiddleSettings`）由「单列滚动」改为「两列 Grid」：左列 `SettingsNav` 分类导航，右列内容区 |
| `Views/MainWindow.xaml.cs` | 新增 `SettingsNav_SelectionChanged` / `ShowSettingsCategory`；`BuildSettingsPanel` 改为按分类构建 |

## 三、实现要点

1. **左栏复用主导航样式** `NavItem`，视觉与左侧主菜单一致。
2. **外观主题**特殊处理：主题画廊是 XAML 静态声明的 `ListBox`（编译期校验资源键，避免运行时丢画廊），
   包进 `AppearancePanel`，切到该分类时显示它、隐藏动态面板，**不重建**。
   其余分类由 `BuildSettingsPanel(category)` 动态构建到 `SettingsPanel`。
3. **分类过滤**：每个分组用 `if (Cat("...")) Guard(...)` 包裹，`Cat` 判断当前分类是否命中。
   分组级 `Guard` 容错保留，任一分类构建失败不影响其它分类。
4. **初始选中**：`OnLoaded` 中 `SettingsNav.SelectedIndex = 0` 触发选中「通用」，
   由事件统一走 `ShowSettingsCategory` 路径（不再直接调用 `BuildSettingsPanel()`）。
5. **布局兼容**：设置分区仍复用既有 `ApplyLayoutFor`——进入设置时右栏折叠、中间列占满，二级菜单因此有充足宽度。

## 四、校验

- XAML 标签配平：`StackPanel` 38/38、`DockPanel` 14/14、`ScrollViewer` 2/2（一致）。
- C# 花括号配平：`balance=0, min=0`。
- 无遗留单参 `BuildSettingsPanel()` 调用（`BuildSettingsPanel` 为私有方法，仅本文件内调用）。
