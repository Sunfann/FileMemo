# 功能记录 —— 待办提醒

> 需求：为待办事项增加「到点提醒」。到达提醒时间后自动弹出通知（托盘气泡 + 提醒窗口），
> 支持稍后提醒与标记完成。纯本地实现，不依赖任何云服务。

## 二、数据模型

- `TaskItem.RemindAt`（`DateTime?`）：提醒时间，为空则不提醒。
- `TaskItem.Reminded`（`bool`）：本轮是否已提醒，避免重复弹出。
- 数据库列：`remind_at TEXT`、`reminded INTEGER`（默认 0），加索引 `ix_task_remind`。
- 迁移为幂等：逐条 `try/catch` 执行 `ALTER TABLE`，列已存在时忽略。

## 三、提醒流程

1. `ReminderService.Start()` 按 `ReminderCheckSeconds`（默认 30 秒）启动 `DispatcherTimer`；
   启动时立即检查一次，以补发应用未运行期间已到点的提醒。
2. 每次 `Check()` 查询 `remind_at <= now`、`done=0`、`reminded=0` 的待办
   （`now` 会加上「提前提醒分钟数」）。
3. 对每条命中项：`MarkTaskReminded(id)` → 写时间线 → 触发 `TaskDue` 事件。
4. `App` 订阅事件，在 UI 线程：弹出托盘气泡 + 打开 `ReminderWindow`。
5. 用户可「稍后提醒 10 分钟」（重置 `remind_at` 与 `reminded`）、「标记完成」或「知道了」。

## 四、设置项（设置 → 通用 → 待办提醒）

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 启用待办提醒 | 开 | 关闭后停止轮询 |
| 检查间隔（秒） | 30 | 10 ~ 600，越小越准时 |
| 提前提醒（分钟） | 0 | 0 = 准点；>0 为提前量 |
| 允许稍后提醒 | 开 | 控制弹窗是否显示「稍后提醒」按钮 |

## 四·补、提醒时间录入（已优化：更直观 / 更快速）

> 早期版本要求手输 `yyyy-MM-dd HH:mm` 文本，不够直观、不够快。现改为「点一下预设即设好」。

**快速待办窗口**（`Views/QuickTaskWindow.xaml(.cs)`）：
- **快捷预设按钮**（点一下即填 */}
  - `+15 分钟` · `+1 小时` · `今晚 20:00`（已过则顺延明天）· `明天 09:00` · `明天此时` · `清除`
- **可视化选择器**：`DatePicker`（日期）+ 小时 `ComboBox`（00–23）+ 分钟 `ComboBox`（00–59）
- **实时预览**：底部即时显示「将于 yyyy-MM-dd HH:mm 提醒 / 未设置提醒」
- 默认不提醒；点预设或选日期才启用

**主窗口待办详情**（`Views/MainWindow.xaml(.cs)`）：
- 同样提供预设按钮（`+15 分钟` / `+1 小时` / `今晚 20:00` / `明天 09:00` / `清除`）
- 点按钮即时写入 `SelectedTask.RemindAt` 并保存，同时回填文本框
- 保留文本框供精确编辑（`yyyy-MM-dd HH:mm`），两者双向一致

## 五、容错设计

- 迁移、轮询、弹窗、托盘气泡全部 `try/catch`，任一失败不影响主程序。
- 提醒窗口的「稍后提醒 / 完成」写库失败仅忽略，不抛出到 UI。
