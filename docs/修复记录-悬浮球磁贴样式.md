# 变更记录：悬浮球改为「圆角磁贴」样式 + 新图标

> 目标项目：**FileMemo（文笺）**（WPF）
> 日期：2026-09-30
> 参考：`PixPin_2026-09-30_12-52-46.gif`（样式）、`ChatGPT Image 2026年9月27日 14_30_40.png`（图标）

---

## 1. 需求

- 将悬浮球由当前样式改为参考 GIF 的样式：**深灰圆角方形「磁贴」**（不再是圆形玻璃球）。
- 磁贴中央改用用户提供的「文件夹 + 便签」图标。

## 2. 实现

### 2.1 视觉结构（`Views/FloatingBallWindow.xaml.cs` → `BuildStage`）

原实现：`_orbBody` 为 `Ellipse`（圆形玻璃球，`Fill` 由 `MakeOrbGlassBrush` / `ball.png` 提供）。

新实现：`_orbBody` 改为 `Grid`，包含：
1. **圆角底板**（`Rectangle`）：
   - `RadiusX = RadiusY = d * 0.30`（圆角方形）；
   - 深灰竖向渐变 `#45454D → #2A2A31`，1px 边框 `#56565F`；
2. **中央图标**（`Image`）：`d * 0.66` 边长，`Stretch=Uniform`，居中，内容取新贴图 `Assets/ball_tile_icon.png`。

- 字段类型由 `Ellipse? _orbBody` 改为 `Grid? _orbBody`；
- 阴影改为更贴合磁贴的 `DropShadowEffect`（Blur 14 / Depth 2 / Opacity 0.35）；
- 移除了不再使用的 `baseColor`（原仅供圆球 Fill 使用）。

### 2.2 新增资源

- 由用户图标裁剪透明边距、居中补白、缩放为 256×256，导出为
  `src/FileMemo.App/Assets/ball_tile_icon.png`；
- 在 `FileMemo.App.csproj` 中登记为内嵌资源：
  ```xml
  <None Remove="Assets\ball_tile_icon.png" />
  <Resource Include="Assets\ball_tile_icon.png" />
  ```
  （与既有 `appicon.png` / `ball.png` 保持一致的打包方式）

## 3. 修改文件清单

| 文件 | 变更 |
|---|---|
| `Views/FloatingBallWindow.xaml.cs` | `_orbBody` 由 `Ellipse` 改为 `Grid` 磁贴；新增圆角底板 + 中央图标；字段类型与阴影同步调整 |
| `FileMemo.App.csproj` | 新增 `ball_tile_icon.png` 内嵌资源登记 |
| `Assets/ball_tile_icon.png` | 新增图标贴图（256×256，来自用户提供图标） |

## 4. 交互保持不变

球体的拖拽 / 悬停 / 贴边收拢 / 右键（光环开关）/ 卫星与进度弧等行为逻辑**均未改动**，
`_orbBody` 的鼠标事件、`Canvas` 定位、`RenderTransform` 仍照常绑定到新的 `Grid` 上。

## 5. 验证建议

1. 重新生成：`dotnet build FileMemo.sln -c Debug`。
2. 运行后确认：悬浮球显示为**深灰圆角磁贴**，中央为「文件夹 + 便签」图标。
3. 拖拽、贴边收拢、右键开关光环等交互正常。
4. 如需微调：`cornerRadius = d * 0.30` 控制圆角，`iconSize = d * 0.66` 控制图标占比。
